# 数据库分析工作台

入口：`/<domain>/database`，支持 tribology、conductivity 和 diffusion。

## 使用方式

- **Table**：默认紧凑表格。点击列标题排序；Columns 选择显示字段；点击记录编号打开详情，点击带证据的数值打开原文。Standardized / As reported 切换标准单位与原始写法。
- **Plot**：选择横纵轴和对数坐标。默认按测试方法分面，也可按论文或阳离子着色。拖框或 Select group 筛选记录，表格与 Export visible 同步；Clear plot selection 取消选区。
- **Compare**：最多加入 6 条记录，支持跨筛选保留。可只看差异和缺失项，查看字段证据，并导出对比 CSV。对比篮保存在当前页面会话中。
- **Advanced filters**：组合测试方法、组成/环境关键词、数值上下界及缺失值条件。数值条件使用字段标注的标准单位，区间需完整落入范围。
- **Data & evidence coverage**：查看字段覆盖及主指标的证据类别，按直接、推断、假设或未评估证据筛选。
- **Saved views**：保存筛选、列、排序、单位和图表设置到当前浏览器。Copy view link 复制同一站点的可恢复链接；接收者仍需具备站点访问条件。
- **Snapshot JSON**：下载当前筛选结果的完整记录、条件、来源证据、视图设置和导出时间。保存视图重新查询当前数据库，JSON 快照保留导出时的数据。

## 分析边界

散点图使用标准单位；范围值、受限定的量值、缺失值和不适合对数轴的数值会按规则排除，并展示数量与原因。图上最多显示 3,000 个合格点；应缩小筛选范围查看其余记录。

字段相同不等于实验可直接比较。对比时仍需检查方法、尺度、表面和环境条件。当前版本未从文字描述推算误差条。

化学结构搜索沿用精确匹配；结构相似度/子结构搜索、服务端分页和跨设备保存视图属于后续迭代。
