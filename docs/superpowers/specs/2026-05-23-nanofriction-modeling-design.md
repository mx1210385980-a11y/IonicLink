# 纳米摩擦智能建模模块设计

日期：2026-05-23

## 背景

本模块用于在建模页面内提供一条独立、专业、易理解的纳米摩擦建模体验。它复现硕士论文最后的核心成果：基于含界面膜厚的数据集，训练分区混合预测模型，并用固定测试集、外部文献验证和超低摩擦趋势共同说明结果可信度。

公开界面不出现内部缩写、人名或文件代号。模块面向材料学院学生和企业用户，语言应准确但简单，避免软件工程术语。必要算法名称可以出现在详情层，首页和按钮优先使用材料与建模语境。

## 用户目标

用户进入模块后应能完成四件事：

1. 了解研究对象：离子液体在固体界面处的纳米摩擦系数。
2. 看到论文最终模型的复现成果：测试集 R2=0.991，外部文献验证 R2=0.985。
3. 一键复现论文模型：载入内置数据、校验固定划分、运行候选模型、确认最优模型。
4. 用简单专业的方式理解结果：哪些离子结构、表面性质、实验条件和膜厚特征影响预测。

## 公开命名与文案规则

模块名称使用“纳米摩擦智能建模”，短入口可用“纳米摩擦建模”。

文案使用以下表达：

- “分区混合预测模型”：解释为“先判断摩擦区间，再调用对应模型预测”。
- “三模型融合”：总览层表达 CatBoost、Random Forest、XGBoost 的组合。
- “拟合度 R2”：说明预测值与真实值的一致程度。
- “平均误差 MAE”：说明预测平均偏差。
- “RMSE”：说明对较大误差更敏感的指标。
- “外部文献验证”：表示模型在训练之外的文献样本上检验。
- “特征贡献解释”：总览层表达 SHAP，详情层可标注 SHAP。

公开界面避免内部缩写、开发实现术语和其它明显的软件开发语境表述。用户只需要看到研究对象、数据基础、复现过程、结果可信度、机理解释和应用入口。

## 页面结构

模块放在建模页内，作为独立子模块入口。推荐主视图由三层组成：

1. 成果总览
   - 显示研究对象、模型目标和一句话方法说明。
   - 显示核心指标卡：含膜厚数据集 212 条、固定划分 169/37/6、测试集 R2=0.991、外部文献 R2=0.985、最优结构“三模型融合”。
   - 提供主操作：“开始复现论文模型”。

2. 复现实验链
   - 步骤为“载入内置数据”“校验固定划分”“复现候选模型”“确认最优模型”。
   - 每一步显示当前状态、完成时间和关键结果。
   - 若数据已载入或模型已训练，页面应复用已有结果，不要求用户重复等待。

3. 证据视图
   - “成果总览”：汇总论文指标、当前复现指标和是否达到论文目标。
   - “固定划分”：显示训练集、测试集、外部文献验证集数量和摩擦系数分布。
   - “候选模型”：比较二模型融合、三模型融合等候选方案，突出最优模型。
   - “外部验证”：展示 6 个外部文献样本真实值与预测值，并说明超低摩擦趋势验证。
   - “影响因素”：展示低、中、高摩擦区间的关键影响因素，使用“表面性质”“膜厚”“滑动速度”“离子疏水性”等材料语汇。

## 建设方案

采用“专题页面 + 复用已有训练能力”的方案。

已有能力包括内置数据导入、固定划分、模型训练、运行记录和模型指标计算。新模块主要把这些能力组织成一条面向材料用户的专业体验，而不是让用户进入通用训练工作台后自行寻找论文复现入口。

新增建设内容：

- 建模页增加“纳米摩擦建模”子入口。
- 新建专题页面承载成果总览、复现实验链和证据视图。
- 增加一个专题汇总能力，返回内置数据状态、固定划分数量、推荐模型结果、候选模型对比和论文目标指标。
- 现有通用建模工作台继续保留，用于更自由的模型探索；专题页面聚焦论文成果复现和材料解释。

## 数据与结果口径

模块以内置的含膜厚 CSV 数据文件为主要数据基础，但公开界面只称为“含界面膜厚数据集”。

固定划分口径：

- 训练集：169 条
- 测试集：37 条
- 外部文献验证集：6 条
- 总样本：212 条

论文目标指标：

- 最优模型：CatBoost 门控，CatBoost + Random Forest + XGBoost 三模型融合，CatBoost 作最终融合模型。
- 测试集：R2=0.991，MAE=0.057，RMSE=0.089。
- 外部文献验证：R2=0.985，MAE=0.040，RMSE=0.046。

外部实验验证口径：

- 用于说明超低摩擦区间趋势识别能力。
- 首页不堆叠过多数值，只展示趋势对照和简短结论。

## 状态与提示

用户看到的状态应以研究任务表达：

- “尚未载入数据”
- “数据已准备”
- “正在复现模型”
- “复现完成”
- “结果未达到论文目标，建议检查依赖或重新运行”
- “缺少算法运行环境，请安装建模依赖后重试”

提示应说明用户下一步该做什么，避免暴露技术细节。

## 验收标准

模块完成后应满足：

1. 建模页内有独立的“纳米摩擦建模”入口。
2. 页面不出现内部缩写或文件代号。
3. 页面不出现开发实现术语，整体表达适合材料学院学生和企业用户阅读。
4. 用户能一键载入含膜厚数据集并复现论文模型。
5. 页面能展示固定划分 169/37/6 和论文目标指标。
6. 页面能展示候选模型对比、外部文献验证和影响因素解释。
7. 通用建模工作台仍可使用，不被本专题改坏。
8. 完成后通过本地验证，并按仓库要求同步到远程服务器。
